Image to Base64

The Image to Base64 tool turns an image into a Base64 data URI that you can paste straight into HTML, CSS or JSON.

How to use the Image to Base64

  1. Choose an image.
  2. Copy the Base64 text.
  3. Paste it where you need it.

About the Image to Base64

A data URI lets you embed a small image directly in code without a separate file, which can save a request for tiny icons. Choose an image and copy either the full data URI or just the Base64 text. Base64 makes files about one third larger, so it is best for small images only. Conversion happens in your browser.

Tips

  • Use it only for small icons, not big photos.
  • Compress the image first to keep the Base64 string short.
  • Copy the full data URI when pasting into an img tag or CSS url().

Frequently asked questions

When is Base64 useful?

For tiny icons inside CSS or HTML so no extra file request is needed.

Is the image uploaded?

No.

Why is the Base64 text larger than the image?

Base64 represents binary data using text characters, which makes it about 33 percent larger.

Is the image uploaded?

No. The conversion is done locally in your browser.
