UUID Generator

The UUID Generator creates random version 4 UUIDs, one at a time or in bulk, ready to copy.

How to use the UUID Generator

  1. Enter how many you need.
  2. Press Generate.
  3. Copy them.

About the UUID Generator

A UUID is a 128-bit identifier that is practically unique, commonly used as a database key or request ID. Choose how many you need and copy them as a list. They are generated using your browser's secure random source and nothing is stored or sent. Version 4 UUIDs are random and carry no information about time or device.

Tips

  • Generate in bulk when you need seed data for tests.
  • Use lowercase consistently if you compare IDs as text.
  • Do not use a UUID as a secret; it is an identifier, not a password.

Frequently asked questions

Can two UUIDs be the same?

It is so unlikely that for practical purposes it never happens.

Which version is made?

Version 4 (random).

Can two UUIDs be the same?

It is theoretically possible but so unlikely that it is ignored in practice.

What is a version 4 UUID?

It is a UUID built from random numbers, as opposed to versions based on time or names.
