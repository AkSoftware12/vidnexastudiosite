Unit Converter

The Unit Converter converts length, weight, area, volume, speed, data size and temperature between common units instantly.

How to use the Unit Converter

  1. Choose the type of unit.
  2. Enter a value and pick From and To.
  3. Read the converted result.

About the Unit Converter

Pick a category, enter a value and see it converted into other units at the same time, such as kilometres to miles, kilograms to pounds, acres to square metres, litres to gallons or Celsius to Fahrenheit. Data units include bytes, kilobytes, megabytes and gigabytes. It is handy for cooking, travel, shopping and studying. The conversion runs in your browser using standard conversion factors.

Tips

  • Use the swap button to reverse the conversion direction quickly.
  • For temperature, remember that conversions are not a simple multiplication.
  • Check whether a recipe or document uses US or UK gallons and cups, as they differ.

Frequently asked questions

Is bigha accurate?

A bigha changes from state to state. The tool uses one common value, so check local records for land deals.

Which temperature units work?

Celsius, Fahrenheit and Kelvin.

How many kilometres are in a mile?

One mile is about 1.609 kilometres.

Does it support Indian units like acre or bigha?

It supports acre and square metre style area units. Local units such as bigha vary by state, so they are not included.
