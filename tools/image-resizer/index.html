Image Resizer

The Image Resizer changes the width and height of an image in pixels, with an option to keep the aspect ratio.

How to use the Image Resizer

  1. Choose an image.
  2. Enter the new width or height.
  3. Press Resize & download.

About the Image Resizer

Resize photos for profile pictures, forms, social posts and web pages. Enter a new width or height, or a percentage, and the other side follows automatically when the aspect ratio is locked. Download the result as JPG, PNG or WebP. Resizing is done in your browser and your picture is not uploaded.

Tips

  • Keep the aspect ratio locked to avoid stretched pictures.
  • Make images smaller rather than larger, because enlarging makes them blurry.
  • Follow the exact pixel size requested by the form or website you are uploading to.

Frequently asked questions

Does it keep the aspect ratio?

Yes, when 'Keep proportions' is ticked.

Is there a size limit?

Up to 10000 pixels on each side, or whatever your device memory allows.

Will resizing reduce the quality?

Making an image smaller keeps it sharp. Enlarging it can make it look soft, because new pixels must be guessed.

What size should I use for the web?

For most web pages 1200 to 1600 pixels wide is enough. Use smaller sizes for thumbnails and icons.
