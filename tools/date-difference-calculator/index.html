Date Difference Calculator

The Date Difference Calculator tells you the number of days, weeks, months and years between two dates.

How to use the Date Difference Calculator

  1. Pick the start date.
  2. Pick the end date.
  3. Read the difference.

About the Date Difference Calculator

Pick a start date and an end date to see the gap as total days and as years, months and days. It is helpful for project deadlines, notice periods, pregnancy or trip countdowns, and counting days since an event. You can choose to include the end date in the count. The calculation uses your browser and no dates are stored.

Tips

  • Tick the include-end-date option if both the first and last day should count.
  • Use it to count working timelines, but remember it does not skip weekends or holidays.
  • Use the Age Calculator when one of the dates is a birth date.

Frequently asked questions

Is the end date included?

The result is the gap between the two dates. Add one day if you want to count both.

Can the start date be later?

Yes. The tool swaps them for you.

Does it include the last day?

By default it counts the difference between the dates. Enable the include-end-date option to count both days.

Does it skip weekends?

No. It counts calendar days, including weekends and holidays.
