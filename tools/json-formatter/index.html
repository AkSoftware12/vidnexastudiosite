JSON Formatter & Validator

The JSON Formatter pretty-prints, minifies and validates JSON and points to the exact place of any error.

How to use the JSON Formatter & Validator

  1. Paste your JSON.
  2. Press Format or Minify.
  3. Copy the result.

About the JSON Formatter & Validator

Paste JSON and choose format to add indentation, minify to remove spaces, or validate to check that it is correct. If the JSON is invalid you get a clear message and the position of the problem, such as a missing comma or quote. It is useful when working with APIs, config files and logs. Everything runs in your browser, so your data is not uploaded.

Tips

  • Look for trailing commas and single quotes, the most common JSON mistakes.
  • Minify JSON before sending it in a request to save bytes.
  • Format minified API responses to read them easily.

Frequently asked questions

Does it fix broken JSON?

No. It tells you what is wrong so you can fix it.

Is my data sent anywhere?

No.

Why does my JSON show an error?

Common causes are a trailing comma, single quotes instead of double quotes, or an unquoted key. The error message shows where it was found.

Is my JSON uploaded?

No. It is parsed locally in your browser.
