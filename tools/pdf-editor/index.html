PDF Editor

The PDF Editor lets you click on existing text and change it in the same font, size and colour, and also add text, images, a drawn signature, ticks, highlights and white boxes, all in your browser.

How to use the PDF Editor

  1. Choose a PDF.
  2. Pick Edit text and click a line to change it, or pick Add text, Whiteout, Highlight, Add image or Sign, then click on the page.
  3. Drag the handle to move an item and the corner square to resize it.
  4. Press Download edited PDF.

About the PDF Editor

Use Edit text, click any line on the page and type the change. The tool reads the font, size and colour of that line, hides the old words and writes the new ones in the PDF's own font when it holds the letters you typed. If it does not, a very close matching font is used instead. You can also fill a form that is not fillable, sign a letter, or highlight important lines. Because the PDF is opened and saved on your own device, private documents such as bank forms and ID copies are not uploaded and there is no page or size limit set by the site. The old words are covered, not deleted: they stay hidden in the file and could still be found by copying or searching, so do not use it to hide private information.

Tips

  • Use Edit text for small corrections such as a date, a name or an amount.
  • Press Enter when you finish a line, then check the page before downloading.
  • Draw your signature slowly on a phone or with a mouse; the tool trims the empty space for you.

Frequently asked questions

Can I change the existing text in a PDF?

You can cover old text with Whiteout and type new text on top. Changing the original text directly is not possible in a browser-only tool.

Is my PDF uploaded?

No. Everything happens on your device.

Can I edit the original text of a PDF?

Yes, line by line. Choose Edit text, click the line and type. The new text is written in the same font when the PDF contains the letters, otherwise in a close matching font. The old text is covered, not removed from the file, so it can still be found by copy or search.

Will the new text look exactly the same?

Usually yes for common fonts such as Arial, Times New Roman, Calibri and Courier. A very decorative or custom font may look slightly different, and the page background behind the text is matched by colour, so photos or gradients can show a faint patch.

Which characters can I type?

Basic Latin letters, numbers and common symbols. Hindi and other scripts cannot be typed yet.

Does Edit text work on scanned PDFs?

No. A scan is a picture, so there are no words to select. Use Whiteout and Add text on top instead.
