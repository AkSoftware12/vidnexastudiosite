Colour Converter

The Color Converter converts colours between HEX, RGB and HSL and shows a live preview of the colour.

How to use the Colour Converter

  1. Pick a colour or type a value in any box.
  2. The other formats update.
  3. Copy the one you need.

About the Colour Converter

Type a HEX code such as #7C3AED, or enter RGB or HSL values, and the other formats update at once. Designers and developers use it to move colours between design tools and CSS. Use the picker to explore and copy the exact value you need. Conversions are calculated locally in your browser.

Tips

  • Use HSL when you want to make a colour lighter or darker by changing one number.
  • Check text and background contrast before using a colour pair on a page.
  • Copy the format your CSS or design tool expects.

Frequently asked questions

What is HEX?

A six-digit code like #7C3AED that stands for red, green and blue.

Can I type a short HEX like #fff?

Yes.

What is the difference between HEX, RGB and HSL?

They describe the same colour in different ways: HEX is a compact code, RGB mixes red, green and blue, and HSL uses hue, saturation and lightness.

Can I use 3-digit HEX codes?

Yes. A short code like #07f is the same as #0077ff.
