Random Number Generator

The Random Number Generator picks one or many random numbers between a minimum and maximum you choose, with or without repeats.

How to use the Random Number Generator

  1. Set the minimum and maximum.
  2. Choose how many numbers.
  3. Press Generate.

About the Random Number Generator

Use it for draws, games, classroom activities, sampling or choosing who goes first. Set the range, how many numbers you need and whether repeats are allowed, then press generate. It uses your browser's built-in random source. For anything that needs cryptographic security, such as passwords, use the Password Generator instead.

Tips

  • Turn off repeats to draw unique numbers, like a lottery or raffle.
  • Generate a sorted list if you want an ordered result.
  • For passwords and keys use the Password Generator, which is designed for security.

Frequently asked questions

Is it truly random?

It uses your browser's secure random generator, which is far better than a simple formula.

Can I avoid repeats?

Yes, tick 'No repeats'.

Is the number truly random?

It is pseudo-random, produced by your browser, which is fine for games and draws but is not meant for security uses.

Can I get numbers without repeats?

Yes. Choose the unique option and the tool draws each number only once.
