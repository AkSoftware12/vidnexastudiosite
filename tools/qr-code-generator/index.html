QR Code Generator

The QR Code Generator creates free QR codes for links, text and Wi-Fi details that you can download as an image.

How to use the QR Code Generator

  1. Type or paste your link or text.
  2. Pick the size, colours and error correction.
  3. Download the PNG or SVG.

About the QR Code Generator

Enter a web address, a message or your Wi-Fi name and password and the QR code appears instantly. Download it as a PNG and put it on a poster, menu, business card or document. The code is generated in your browser, the data is not sent to a server and the codes do not expire. Test every code with a phone camera before printing, and leave a clear margin around it.

Tips

  • Use dark code on a light background for the best scanning.
  • Print the code at least 2 cm wide and test it before printing many copies.
  • Shorter links produce simpler codes that scan faster.

Frequently asked questions

Do QR codes expire?

No. The code simply holds your text, so it works as long as the link you put in it works.

Is it free for business use?

Yes. Codes you make are yours to use.

Do the QR codes expire?

No. The code simply holds the data you entered, so it works for as long as the link or information is valid.

Can I make a Wi-Fi QR code?

Yes. Choose the Wi-Fi option, enter the network name, password and security type, and phones can join by scanning.
