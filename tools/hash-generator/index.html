Hash Generator

The Hash Generator creates SHA-1, SHA-256, SHA-384 and SHA-512 hashes of any text in your browser.

How to use the Hash Generator

  1. Type or paste text.
  2. Hashes appear straight away.
  3. Copy the one you need.

About the Hash Generator

A hash is a fixed-length fingerprint of data. Type or paste text and see all hashes immediately, which is useful for checking integrity or comparing values. The same input always gives the same hash and a tiny change gives a completely different one. Hashes cannot be reversed, but plain SHA hashes are not suitable for storing passwords. Hashing uses your browser's built-in crypto and nothing is uploaded.

Tips

  • Use SHA-256 or higher for new work; SHA-1 is considered weak.
  • Watch for hidden spaces or line breaks that change the hash.
  • Use a dedicated password hashing method such as bcrypt or Argon2 for passwords.

Frequently asked questions

Why is there no MD5?

Browsers do not include MD5. SHA-256 is the better choice today.

Is hashing the same as encryption?

No. A hash cannot be turned back into the text.

Can a hash be reversed?

No. Hashing is one way, though short or common inputs can be guessed.

Which hash should I use?

SHA-256 is a good default. Avoid SHA-1 for security purposes.
