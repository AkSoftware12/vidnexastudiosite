How to Edit a PDF for Free: Add Text, Sign, Highlight and Cover Mistakes

Edit a PDF in your browser: add text to a form, sign, insert an image, highlight and cover a mistake, plus what a browser-only editor cannot do.

Many PDFs are not fillable forms, but you still need to write on them: a date, a name, a tick box or a signature. You do not need to install software for this. A browser-based PDF editor opens the file on your own device, lets you place items on the page and saves a new PDF.

What you can do

  • Edit existing text: click a line and type the change in the same font, size and colour.
  • Add text anywhere on a page, with your choice of size and colour.
  • Draw a signature with your finger or mouse and place it on the page.
  • Insert an image such as a stamp or a scanned signature.
  • Add a tick or a cross.
  • Highlight lines you want to stand out.
  • Cover a mistake with a white box.

Step by step

  1. Open the PDF Editor and choose your file.
  2. Pick Add text and click on the page where the text should start, then type.
  3. Drag the purple handle to move an item. For images, signatures and boxes, drag the corner square to resize.
  4. Use the arrows to go to the next page and repeat.
  5. Press Download edited PDF.

How to correct existing text

Choose Edit text and click the line you want to change. The editor reads that line's font, size and colour, covers the old words and writes your new words in the same style. When the PDF still holds the letters you type, the new text is drawn with the PDF's own font. If you type a letter the PDF never used, the editor switches to a close matching font such as a look-alike of Arial, Times or Calibri, so the line still looks natural. Press Enter when you finish, then check the page.

One thing to know: the old words are covered, not erased. They remain hidden in the file and could still be found by copying or searching. So use this for corrections, not for hiding private information. For scanned pages there is no text to select, so use Whiteout and Add text on top.

What it cannot do

  • Permanently remove the old words from the file or reflow a whole paragraph, which needs desktop PDF software.
  • Type in Hindi or other scripts. The built-in font supports basic Latin letters, numbers and common symbols.
  • Open a password protected PDF without the password.
  • Make a legally certified digital signature. A drawn signature is an image of your handwriting.

Why your file stays private

The editor opens and saves the PDF inside your browser. The file is not uploaded, so bank forms and ID copies stay on your device. See our guide on how browser-based tools work for the details.

Tips for a clean result

  • Zoom the page so you can place text exactly on the line.
  • Use the same colour as the rest of the form, usually black or dark blue.
  • Open the downloaded file and check every page before you send it.

Frequently asked questions

Will edited text look the same as the rest of the page?

For common fonts such as Arial, Times New Roman, Calibri and Courier it usually does. The editor copies the size and colour and matches the background colour. A very decorative font or a photo behind the text can show a small difference, so zoom in and check before you send the file.

Is the signature legally valid?

A drawn signature is an image of your handwriting. Many everyday documents accept it, but some need a certified digital signature or a witnessed signature. Check what the receiver requires.

Can I edit a scanned PDF?

You can add text, signatures and boxes on top of a scanned page. You cannot change the scanned words, because they are part of the picture.
