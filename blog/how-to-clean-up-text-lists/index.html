How to Clean Up Text: Remove Duplicates, Sort Lines and Fix Capitalisation

Practical ways to clean lists and text with a duplicate line remover, a text sorter, a case converter and a slug generator.

Text · 1 min read · Updated 4 November 2026

In this guide

  2. Step 2: sort the list
  3. Step 3: fix capitalisation
  4. Step 4: make clean web addresses
  5. Why do it in the browser?
  6. A quick workflow

Messy lists waste time. Whether it is an email list, a set of keywords or a column copied from a spreadsheet, a few simple steps can make it clean.

Step 1: remove duplicates

Paste your list into the Remove Duplicate Lines tool. It keeps the first copy of each line and deletes the repeats. Turn on case-insensitive matching if you want Apple and apple treated as the same item.

Step 2: sort the list

Use the Text Sorter to arrange lines A to Z, Z to A or by length. Sorting makes it easy to spot near-duplicates and to find an item quickly. There is also a shuffle mode for random draws and team lists.

Step 3: fix capitalisation

The Case Converter changes text to UPPERCASE, lowercase, Title Case or Sentence case. It is perfect for text typed with Caps Lock on. For developers it can also produce camelCase and snake_case names.

Step 4: make clean web addresses

The Slug Generator turns a title into a short, lowercase, hyphen-separated slug. Short slugs that contain the main keyword are easier to read in search results and links.

Why do it in the browser?

These tools run on your device. Customer lists and private notes are not uploaded, which is safer than pasting them into unknown websites.

A quick workflow

  1. Paste the raw list.
  2. Remove duplicates.
  3. Sort A to Z.
  4. Fix the case.
  5. Copy the result back to your document.

Frequently asked questions

Does removing duplicates change the order?

No. It keeps the first occurrence and the original order of the remaining lines.

What is a slug?

A slug is the readable last part of a web address, such as how-to-merge-pdf.
