How to Create a Strong Password (and How a Generator Helps)

Learn what makes a password strong, why length matters most, and how to use a password generator and a password manager safely.

Weak passwords are a leading cause of hacked accounts. A strong password is long, random and used for only one account.

What makes a password strong

  • Length. Each extra character multiplies the number of guesses needed. Aim for at least 14 characters for important accounts.
  • Randomness. Names, birthdays and words like password123 are the first things attackers try.
  • Uniqueness. If one site leaks your password, attackers try it everywhere else.

How the Password Generator works

It uses your browser's cryptographic random generator, which is designed for security, unlike the simple generator used for games. You choose the length and which characters to include, and the password is created on your device. It is not sent anywhere or stored.

Steps

  1. Open the Password Generator and set the length to 14 or more.
  2. Include letters, numbers and symbols if the site allows them.
  3. Copy the password straight into your password manager or the site.
  4. Never reuse it on another account.

Remember all those passwords

Nobody can remember dozens of random passwords. Use a trusted password manager and protect it with one strong passphrase, which is a string of several random words.

Extra protection

  • Turn on two-factor authentication wherever it is offered.
  • Be careful about phishing messages that ask for your password.
  • Change a password at once if a service reports a data breach.

A note about hashes

Sites should store a hash of your password, not the password itself. The Hash Generator shows what hashes look like, but plain SHA hashes are not suitable for storing passwords. Real systems use slow methods such as bcrypt or Argon2.

Frequently asked questions

Is it safe to use an online password generator?

It is safe when the password is generated in your browser and never sent anywhere, as with this tool.

How long should my password be?

At least 12 characters, and 14 or more for email, banking and other important accounts.
