How QR Codes Work and How to Make One for Free

Learn what a QR code stores, how phones read it, how to create QR codes for links and Wi-Fi, and tips for printing codes that scan every time.

Developer · 2 min read · Updated 4 November 2026

In this guide

  2. How to make a QR code
  3. Do QR codes expire?
  4. Tips for printing
  5. Staying safe

A QR code is a square pattern of dark and light modules that stores data such as a web link, a message or Wi-Fi details. Your phone camera reads the pattern and turns it back into the data.

How a QR code is built

  • Three large squares in the corners tell the camera where the code is and which way it faces.
  • The remaining modules store the data in a pattern.
  • Extra error-correction data lets the code still scan if part of it is dirty or covered.

How to make a QR code

  1. Open the QR Code Generator.
  2. Choose what to encode: a link, plain text or Wi-Fi details.
  3. Type the information. For Wi-Fi, enter the network name, password and security type.
  4. Download the code as an image.

Do QR codes expire?

Codes made by this tool hold the data directly, so they do not expire. If the code points to a link, it works as long as that link works. Be careful with services that charge to keep codes working.

Tips for printing

  • Use dark code on a light background with good contrast.
  • Leave a clear blank margin around the code.
  • Print at least 2 cm wide for close scanning and larger for posters.
  • Test the printed code with two or three phones before printing many copies.
  • Shorter links make simpler, easier-to-scan codes.

Staying safe

Only scan codes from sources you trust, because a code can lead to any web address. Look at the link your phone shows before you open it.

Frequently asked questions

What can a QR code store?

Links, plain text, contact details, Wi-Fi details and more. This tool supports links, text and Wi-Fi.

Why will my QR code not scan?

Usually low contrast, too small a print size, or a missing blank border. Make it larger and use dark on light.
