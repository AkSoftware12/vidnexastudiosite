Base64 and URL Encoding Explained With Simple Examples

What Base64 and percent-encoding are, why they exist, when to use them and how to encode or decode text and images safely.

Developer · 1 min read · Updated 4 November 2026

In this guide
  1. What is Base64?
  2. What is URL encoding?
  3. When to use which
  4. How to use the tools
  5. Common problems

Computers often need to send data through systems that only handle plain text. Base64 and URL encoding are two ways of making data safe for those systems.

What is Base64?

Base64 represents any data using 64 safe characters: letters, numbers, plus and slash. It is used to put images in HTML or CSS, send attachments by email and carry data in JSON. Base64 makes data about one third larger, and it is not encryption. Anyone can decode it.

What is URL encoding?

Web addresses can only contain certain characters. Others, such as spaces, ampersands and non-English letters, are replaced by a percent sign and two digits. A space becomes %20, so "cake recipe" becomes cake%20recipe.

When to use which

  • Use URL encoding for text inside a link or query string.
  • Use Base64 to carry binary data, such as a small image, as text.
  • Never use either one to hide a password.

How to use the tools

  1. Open the Base64 Encoder Decoder, paste text and choose encode or decode.
  2. Open the URL Encoder Decoder to make text safe for a link or to read a messy encoded link.
  3. Open Image to Base64 to turn a small image into a data URI you can paste into code.

Common problems

  • Decoding fails if characters were lost when copying.
  • Encoding a whole URL, instead of only its values, can break it.
  • Plus signs in query strings may mean a space in some systems.

Frequently asked questions

Is Base64 a type of encryption?

No. It is just a way of writing data as text and anyone can reverse it.

Why is %20 in my link?

It is the encoded form of a space character.
