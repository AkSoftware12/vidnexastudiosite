What Is JSON? How to Format It and Fix Common Errors

A beginner-friendly guide to JSON, with examples, the most common syntax errors and how to use a JSON formatter to fix them quickly.

Developer · 1 min read · Updated 4 November 2026

In this guide
  1. What JSON looks like
  2. The most common JSON errors
  3. How to use the JSON Formatter
  4. Format or minify?
  5. Keep sensitive data safe

JSON, or JavaScript Object Notation, is a simple text format for storing and sending data. APIs, settings files and apps use it everywhere. It is easy to read but unforgiving: one wrong comma and the whole file fails.

What JSON looks like

Data is written as keys and values inside curly braces, with lists inside square brackets. For example: {"name": "Asha", "age": 25, "skills": ["design", "code"]}.

The most common JSON errors

  • A trailing comma after the last item.
  • Single quotes instead of double quotes around keys and text.
  • Unquoted keys.
  • Missing commas between items or a missing closing bracket.
  • Comments, which JSON does not allow.

How to use the JSON Formatter

  1. Paste your JSON into the box.
  2. Press Format to add neat indentation, or Minify to remove extra spaces.
  3. Press Validate. If the JSON is wrong you see a message and the position of the problem.
  4. Fix the problem and format again.

Format or minify?

Formatted JSON is easier for people to read. Minified JSON removes spaces and line breaks, which makes the data a little smaller to send. Use formatted JSON while working and minified JSON when sending data.

Keep sensitive data safe

The tool parses your JSON in your browser. Even so, avoid pasting live passwords or secret keys into any website.

Frequently asked questions

Why does my JSON say unexpected token?

There is usually a stray character, a missing comma or a trailing comma near the position shown in the error.

Can JSON have comments?

No. Remove comments, or use a format designed for config files that allows them.
